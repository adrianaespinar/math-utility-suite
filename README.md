#  Math & Utility CLI Suite

Math & Utility CLI Suite una herramienta de línea de comandos (CLI) desarrollada en Python, diseñada para automatizar cálculos complejos.

##  Objetivo
El propósito de este proyecto es doble:
1. **Academic Support:** Facilitar la resolución y comprobación de ejercicios de matemáticas (matrices, determinantes, integrales).
