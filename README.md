# Math & Utility CLI Suite

Centro de cálculo y automatización matemática. Una herramienta de línea de comandos (CLI) en Python diseñada para resolver, comprobar y entender problemas complejos.

##  Objetivo
Facilitar el estudio y la comprobación de ejercicios académicos avanzados:
1. **Álgebra Lineal:** Operaciones con matrices, cálculo de determinantes, inversas y sistemas de ecuaciones.
2. **Análisis Matemático:** Resolución y comprobación de integrales y derivadas.
3. **Automatización Personal:** Scripts útiles para optimizar flujos de estudio diarios.

##  Estructura del Proyecto
```text
math-utility-suite/
│
├── main.py                # Interfaz principal (menú interactivo)
├── modules/               # Módulos de lógica funcional

│   ├── calculo.py         # Análisis y cálculo matemático
│   └── utilities.py       # Utilidades y automatizaciones varias
├── requirements.txt       # Dependencias del proyecto
